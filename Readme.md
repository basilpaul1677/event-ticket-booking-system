# Event & Ticket Booking System

A microservices-based Event & Ticket Booking System built using Java, Spring Boot, React.js and MySQL.

## Services

- API Gateway
- User Service
- Event Service
- Booking Service
- Notification Service

## Frontend

- React.js
- Vite
- Axios
- React Router
- Context API

## Backend

- Java 21
- Spring Boot 4.1.1
- Spring Security
- JWT
- Spring Data JPA
- MySQL
- REST APIs

## User Roles

- USER
- EVENT_CENTER
- ADMIN
